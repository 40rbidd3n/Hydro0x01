# Security Policy

## Reporting Security Vulnerabilities

Please do not disclose suspected security vulnerabilities in public GitHub Issues, Discussions, or pull requests.

Please report security vulnerabilities privately using GitHub's Private Vulnerability Reporting feature:

- [Report a vulnerability](https://github.com/40rbidd3n/Hydro0x01/security/advisories/new)
- [Repository Security tab](https://github.com/40rbidd3n/Hydro0x01/security)

Please include the following information in your report:

- **Affected component:** The relevant file, module, endpoint, or configuration.
- **Technical details:** A clear explanation of the suspected vulnerability.
- **Reproduction steps:** Minimal, reproducible steps or a proof of concept.
- **Potential impact:** The security consequences and affected deployment scenarios.
- **Suggested remediation:** If available, recommendations for addressing the issue.

Please allow reasonable time for investigation and remediation before publicly disclosing the vulnerability. Please do not access, modify, or disrupt systems or data belonging to other users while investigating a suspected issue.

Thank you for helping keep Hydro0x01 and its users secure.
